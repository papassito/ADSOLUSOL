# AD SOLUSOL — AI Governance

## Propósito

AI es una capacidad auxiliar del dominio Marketing. No sustituye las fuentes autoritativas de campañas, métricas ni presupuesto.

## Puede

- resumir desempeño;
- explicar variaciones;
- clasificar señales;
- producir recomendaciones;
- sugerir experimentos;
- asistir en generación de contenidos.

## No puede por inferencia

- crear clics o impresiones;
- afirmar conversiones no observadas;
- alterar gasto histórico;
- activar campañas sin autorización;
- inventar datos para completar análisis.

## Provenance

Toda recomendación debe poder distinguir:

```text
OBSERVED DATA
DERIVED METRIC
MODEL INFERENCE
RECOMMENDATION
```

## Proveedor

Esta especificación no fija un proveedor AI concreto. El contrato debe permanecer desacoplado del proveedor.
