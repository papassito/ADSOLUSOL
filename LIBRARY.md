## Propósito

Este archivo es el índice maestro de la documentación de **AD SOLUSOL**. La biblioteca documenta exclusivamente el dominio publicitario y sus integraciones directas. No contiene arquitectura fiscal, contable ni tributaria.

## Regla de autoridad

1. `ADSOLUSOL.md` define identidad, propósito y frontera del producto.
2. `REQUIREMENTS.md` define obligaciones verificables.
3. `COMPONENTS.md` define responsabilidades internas.
4. `CONTRACTS.md` define contratos de datos y comportamiento.
5. `INTEGRITY.md` define invariantes de veracidad, idempotencia y preservación.
6. `MOTOR.md` define el núcleo publicitario.
7. Los documentos especializados detallan cada dominio sin redefinir los anteriores.
